# Task 3 – Data Visualization

## Objective
To transform raw data into meaningful visualizations that clearly
communicate patterns, trends, and relationships.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Work Performed
- Loaded and explored the dataset
- Cleaned the data
- Created different charts
- Compared variables
- Analyzed trends and patterns
- Presented insights using visualizations

## Visualizations
- Bar Chart
- Pie Chart
- Histogram
- Scatter Plot
- Box Plot
- Correlation Heatmap

## Conclusion
Data visualization helps make complex information easier to
understand and supports better data-driven decision making.
